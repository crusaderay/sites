隐私政策

晴忆（Raylore）由 Ray Zhang 开发。本政策适用于 iPhone App 及这些晴忆网页。生效日期：2026 年 10 月 12 日。

你的照片在本机整理。我们不会将照片、视频、照片库素材标识或逐张整理决定上传至开发者运营的服务器、广告服务或统计服务。

照片、视频与本机记录

获得 iOS 照片权限后，晴忆读取你允许访问的部分或全部照片库项目，用于预览、按日期回顾和整理。照片日期等元数据在本机用于这些功能。整理进度、回顾分组和偏好设置保存在设备上。晴忆没有自有帐号或跨设备同步服务。卸载 App 可能移除本机记录。

收藏、加入相册和确认删除通过 Apple 照片接口执行。加入「待复核」本身不会删除照片。照片库变更可能根据你的 Apple 设置通过 iCloud 照片同步。系统「最近删除」规则及设备备份由 Apple 管理，晴忆无法控制。你可以随时在 iOS 设置中更改照片访问范围。

照片地点名称与提醒

显示照片地点名称时，晴忆可能将照片已有的坐标发送至 Apple 的地点服务，换取可读的地点名称。App 不请求设备当前位置，也不向广告或统计服务传入照片坐标。可选提醒是本地通知，需要你的授权，可以在 iOS 设置中关闭。

广告与隐私同意

晴忆底部包含固定的 Google AdMob 横幅广告。App 请求非个性化广告，关闭 Google publisher first-party ID，也不请求 Apple 跨 App 跟踪许可。非个性化广告仍涉及数据处理：Google Mobile Ads SDK 可能处理 IP 地址及据此推断的大致位置、App 或设备相关标识、广告展示与互动、性能或诊断信息，用于广告投放、衡量及防止滥用。

适用时，Google User Messaging Platform 会显示隐私同意选项。需要持续提供隐私选择时，你可以在设置中重新打开「广告隐私选项」。可选统计与广告选择彼此独立。我们不会向广告 SDK 传入照片、照片库标识、照片坐标、相册名或逐张保留／待复核决定。

可选的 App 使用情况统计

使用情况统计默认关闭。如果你在设置中开启「分享使用情况统计」，Google Analytics for Firebase 会帮助我们了解哪些功能对用户有用。只有你主动开启后，App 才会为统计初始化 Firebase。

开启后，该服务处理假名化的统计实例标识、App 与操作系统版本、设备型号、语言、会话和使用事件，以及用于推断大致地区的 IP 地址等网络信息。我们的自定义事件只包含固定的页面名、模式名和粗分组的每组数量。不会发送照片或视频内容、照片素材标识、相册名称或标识、照片日期或坐标、逐张整理决定、输入文本或完整错误信息，也不设置用户 ID。

统计集成不采集广告标识符 IDFA；IDFV 采集以及统计的广告存储、广告用户数据与个性化功能均关闭。关闭使用统计后，将停止新数据采集、清除设备上的统计缓存并重置本地统计实例标识。这不会追溯删除 Google 服务器上已经处理的数据。

这些网站页面

这些页面由 GitHub Pages 托管。托管服务可能为网页交付、安全和运营日志处理 IP 地址等请求信息。在你通过页脚「网站隐私选项」允许之前，这些晴忆页面不会加载 Google Analytics 脚本。

如果允许网站统计，Google Analytics 会使用 Cookie 和假名化标识、浏览器与设备信息、页面访问及大致地区信息。这些页面关闭 Google signals 和广告个性化；页面浏览配置会省略网址查询参数、片段标识和来源网址。由这些页面设置的统计 Cookie 有效期配置为最长 60 天。你的选择保存在当前浏览器的本地存储中。

你可以随时在页脚关闭网站统计。这会停止这些页面的新统计，并从当前浏览器移除它们的晴忆统计 Cookie。App 与网站统计的选择互不影响。ray-zhang.xyz 的其他页面可能有各自的统计设置。

服务方、保留与个人选择

Apple、Google 和 GitHub 根据各自政策处理信息，处理地点可能位于你所在国家或地区之外。Google 广告和统计服务依其设置与政策保留数据；重置本地标识并不等于删除之前采集的全部服务器数据。我们使用统计改善晴忆，通过广告支持 App 运营，不经营照片信息交易服务。

请参阅 Apple 隐私政策、Google 隐私政策、Google 广告说明和 GitHub 隐私声明。根据所在地区，你可能享有访问、更正、删除或反对特定处理的权利，请通过下方邮箱联系。由于晴忆没有帐号系统，也不向我们上传照片库，若缺乏额外信息，我们可能无法定位某个假名化统计记录。

支持邮件与政策更新

发送邮件时，我们会收到你的邮箱地址及你选择提供的内容，用于回复问题、排查故障和保留必要的支持记录。除非确有需要，请不要发送私人照片或其他敏感信息。政策变更时，我们会更新上方生效日期。
